# Quota Float v0.3.0

## What's new

- Unifies themes and skins under one Appearance menu.
- Adds macOS Glass, tvOS Focus, and Liquid Glass appearances.
- Turns Dark into a complete grey-space appearance while preserving Light as the default.
- Adds always-on-top and locked window modes for both widget sizes.
- Keeps the compact widget anchored when expanding and collapsing.
- Prevents locked widgets from reacting to hover or drag and gives them an idle translucent appearance.
- Keeps the widget visible across macOS Spaces and removes the former paid-feature boundary.

## Downloads

- Windows: unsigned `.exe` / `.msi` installers.
- macOS: unsigned Universal `.dmg` for Apple Silicon and Intel Macs.

The release is not code-signed or notarized. macOS may require right-clicking the app and choosing Open, or allowing it in System Settings -> Privacy & Security.

## Privacy

Quota Float remains local-first: it reads the existing Codex Desktop login state only for quota requests and does not upload prompts, chats, raw quota responses, or local credentials.
